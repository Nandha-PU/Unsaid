🔒 ZERO-RETENTION PRIVACY ARCHITECTURE

Your words belong only to you. Here is exactly how our backend guarantees zero data retention:

1. SHA-256 HASH ONLY

In app/audit.py, drafts are immediately converted to an irreversible cryptographic SHA-256 digest (hash_text()) for rate-limiting. Plaintext is discarded immediately.

2. RAW DRAFTS NEVER LOGGED

As written in our audit pipeline: "RAW DRAFT IS NEVER LOGGED OR RETAINED." Server logs record latency, character counts, and hashes—never your messages.

3. NO DATABASE & NO ACCOUNTS

This repository has zero database tables (no SQLite, Postgres, or MongoDB). Every request is processed entirely in ephemeral RAM and disappears when finished.

4. EPHEMERAL LLM CALLS

Calls to Google Gemini GenAI SDK run with ephemeral session configurations without training flags on user data.
